# Security policy

The latest published version receives security fixes. Before the first release,
reports against main are welcome.

Use [private vulnerability reporting](https://github.com/EstySD/LookUpLinux/security/advisories/new).
If unavailable, open an issue requesting a private contact without posting
exploit details. No response deadline is guaranteed.

Include version, platform, reproduction and impact. Do not attach private
dictionaries, credentials, screenshots or history databases. Open dictionaries
only from sources you trust. Online translation sends text to external services
as described in the README.
