# Retrospective

## v1.0 LookUp Linux — 2026-11-01

Delivered all 32 requirements across nine phases and 43 plans. Final independent Phase 8 verification is 7/7. Host and target each run 797 tests at the same code revision; the target has no skips or failures. The current physical30 median is 1088.246 ms, with p95 1431.759 ms. Genuine fullscreen Wesnoth and AssaultCube routes include useful lookups and returned gameplay control.

### What worked

- Immutable source images, actual selected-word observations and strict clock/process identities made the captured-game gap reproducible. A general same-image PSM6-to-PSM11 retry fixed the demonstrated segmentation case while preserving successful PSM6 behavior.
- Separate raw evidence, source/package/runtime inventories and independent review caught report-binding defects that passing test counts alone would miss.
- A dedicated clone, pinned endpoint/DMI guards and recorded host actions preserved the explicit boundary around the externally owned original VM.
- Saving the post-manual SQLite backup with WAL preserved the user's actual 16 words, one card and current settings through later tests and cleanup.

### Lessons

- Diagnose exact captured pixels before trying further game/font configurations. Frozen-source comparisons distinguish OCR segmentation from transport, observer and rendering errors.
- Qt timeout tests need bounded event/predicate synchronization. A fixed wall-clock wait can finish before an overdue timer is dispatched under load.
- Multiprocessing fixtures must retain Barrier/Queue objects until child startup and joins complete; an expected deadline error must not create unrelated SemLock tracebacks.
- Preserve complete shortcut snapshots and typed action assignments. KConfig's nested product section must not be mistaken for an unrelated user binding.
- Treat cleanup readbacks, source loading and persistence as independently fallible. A hard-terminated controller cannot run finally; persist the prior baseline and record explicit recovery rather than claiming automatic completion.
- Freeze all code and test dependencies before the final host/target pair. Bind the real revision, tree, root PKGBUILD and current code bytes; retain failed runs without relabeling or filtering their output.
- Agent acceptance and a user-provided manual session are different evidence. Finishing the manual session alone does not assert a human pass.

### Preserved limits

The historical Phase 7 original-VM preservation exception remains explicit. VM live-meaning availability is 0/6, with no UI latency claimed. Borderless, a second output, the friend's hardware and live third-party MDX/DSL samples remain outside the demonstrated coverage. These limits and all rejected attempts remain in the [closeout audit](milestones/v1.0-MILESTONE-AUDIT.md) and raw phase records.
