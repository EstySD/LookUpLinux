# Requirements: LookUp Linux

**Defined:** 2026-10-23
**Core Value:** Хоткей над английским словом даёт перевод в оверлее у курсора примерно за 1–2 секунды, и слово попадает в базу со счётчиком.

## v1 Requirements

Прод-версия, близкая к Lookupper для Windows (решение от 2026-10-24).

### Trigger & App

- [ ] **TRIG-01**: Пользователь нажимает глобальный хоткей (по умолчанию Meta+Shift+D) в любом приложении, и запускается поиск
- [ ] **TRIG-02**: Повторное нажатие заменяет текущий попап; быстрые нажатия подряд не портят базу
- [ ] **TRIG-03**: Приложение работает в фоне с иконкой в трее; меню трея: «Слова», «Повторение», «Настройки», «Выход»
- [ ] **TRIG-04**: Приложение запускается при входе в систему (отключается в настройках)

### Capture

- [ ] **CAPT-01**: Если нового выделения нет, слово под курсором распознаётся OCR со скриншота текущего монитора
- [ ] **CAPT-02**: Если есть новое короткое выделение (не то, что уже переводили), берётся оно без OCR
- [ ] **CAPT-03**: Если курсор между словами, берётся ближайшее слово; мусор или низкая уверенность OCR дают «не найдено» и не сохраняются
- [ ] **CAPT-04**: Составные слова распознаются как одна единица. Над «break» в «break out» сначала ищется «break out», потом «break». Слова через дефис склеиваются

### Dictionaries & Translation

- [ ] **TRAN-01**: Слово ищется в офлайн-словарях из папки словарей в форматах StarDict, Lingvo DSL и MDX (по умолчанию Mueller 7 EN→RU); статьи из нескольких словарей показываются по порядку
- [ ] **TRAN-02**: Если слова нет ни в одном словаре или выделена фраза, используется онлайн-перевод; ошибка показывается в попапе, ожидание не больше ~3 с
- [x] **TRAN-03**: Повторный поиск уже найденного слова берётся из кэша без сети
- [x] **TRAN-04**: Если формы слова нет в словаре (running, ran, books), ищется базовая форма (run, book) по простым окончаниям и списку неправильных глаголов
- [ ] **TRAN-05**: Исходное предложение переводится онлайн и показывается под ним; без сети попап работает, но без перевода предложения

### Popup

- [ ] **POP-01**: Попап-карточка появляется у курсора в пределах экрана: слово, транскрипция, части речи с вариантами значений, статья словаря, исходное предложение с переводом, «искали N раз»
- [ ] **POP-02**: Попап закрывается по клику вне него, Esc, потере фокуса или таймауту
- [ ] **POP-03**: Каждое нажатие что-то показывает: «не найдено», «нет сети», «не установлен пакет X»
- [ ] **POP-04**: Кнопка в попапе добавляет слово в карточки для повторения (с контекстом и переводом)
- [ ] **POP-05**: Попап и окна следуют теме KDE (Breeze, светлая и тёмная)

### Data

- [x] **DATA-01**: Каждое найденное слово сохраняется с переводом, контекстом (распознанной строкой), счётчиком поисков, временем первого и последнего поиска
- [x] **DATA-02**: Перед подсчётом слово нормализуется: регистр, крайняя пунктуация, кавычки, `'s`
- [ ] **DATA-03**: Выделенная фраза из 2–4 слов переводится и сохраняется как одна запись; длинный текст только показывается

### Word List

- [ ] **LIST-01**: Окно со списком сохранённых слов, по умолчанию отсортированных по счётчику; сортировка кликом по колонкам
- [ ] **LIST-02**: В окне есть поиск, удаление слов и добавление в карточки

### Learning

- [ ] **LEARN-01**: Окно повторения показывает карточки по интервальному расписанию с ответами Again / Hard / Good / Easy и интервалами на кнопках, как у Lookupper
- [ ] **LEARN-02**: Карточки экспортируются в CSV и в файл, который импортируется в Anki (слово, перевод, контекст)

### Settings

- [ ] **SET-01**: Окно настроек: хоткей, словари (вкл/выкл, порядок), таймаут попапа, онлайн-перевод вкл/выкл, автозапуск

### Install

- [ ] **INST-01**: Пакет для Arch через PKGBUILD (`makepkg -si`): приложение, зависимости, словарь Mueller 7, ярлыки, регистрация хоткея; чистое удаление через pacman
- [ ] **INST-02**: README на русском: установка, ручная настройка хоткея, `lookup --doctor` для диагностики

### Performance

- [ ] **PERF-01**: Медиана от нажатия хоткея до попапа не больше 1,5 с в VM Дениса (Arch + KDE)

## v2 Requirements

- **LEARN-03**: Статус слова «знаю / учу»
- **LEARN-04**: Синхронизация с Anki в один клик (AnkiConnect), экспорт в Quizlet
- **DICT-02**: Произношение (аудио), CEFR, синонимы
- **DICT-03**: Формат Yomitan
- **CARD-01**: Скриншот сцены и приложение-источник в карточке слова
- **PUB-01**: Публикация пакета в AUR

## Out of Scope

| Feature | Reason |
|---------|--------|
| X11, GNOME и другие DE | У друга KDE Plasma 6, X11-сессию убрали в Plasma 6.8 |
| Машинный офлайн-перевод (Argos) | Для слов хватает словарей, фразы и предложения идут онлайн |
| Языки кроме EN→RU | Друг просил английский |
| Геймпад, перевод всего экрана | Не просили |
| Проверка на железе друга | Решено тестировать только в VM Дениса |
| Лемматизация через NLTK/spaCy | Тяжёлая зависимость; хватит TRAN-04 |
| Реверс-инжиниринг Lookupper | Поведение видно снаружи, риск EULA |
