# Requirements: LookUp Linux

**Defined:** 2026-10-23
**Core Value:** Хоткей над английским словом даёт перевод в оверлее у курсора примерно за 1–2 секунды, и слово попадает в базу со счётчиком.

## v1 Requirements

### Trigger

- [ ] **TRIG-01**: Пользователь нажимает хоткей KDE (по умолчанию Meta+Shift+D) в любом приложении, и запускается поиск
- [ ] **TRIG-02**: Повторное нажатие заменяет текущий попап; одновременные нажатия не портят базу

### Capture

- [ ] **CAPT-01**: Если нового выделения нет, слово под курсором распознаётся OCR со скриншота текущего монитора
- [ ] **CAPT-02**: Если есть новое короткое выделение (не то, что уже переводили), берётся оно без OCR
- [ ] **CAPT-03**: Если курсор между словами, берётся ближайшее слово; мусор или низкая уверенность OCR дают «не найдено» и не сохраняются
- [ ] **CAPT-04**: Составные слова распознаются как одна единица. Над «break» в «break out» сначала ищется «break out», потом «break». Слова через дефис склеиваются

### Translation

- [ ] **TRAN-01**: Слово сначала ищется в офлайн-словаре StarDict (по умолчанию Mueller 7 EN→RU); пользователь может положить свои StarDict-словари в папку
- [ ] **TRAN-02**: Если слова нет в словаре или выделена фраза, используется онлайн-перевод; ошибка показывается в попапе, ожидание не больше ~3 с
- [ ] **TRAN-03**: Повторный поиск уже найденного слова берётся из кэша без сети
- [ ] **TRAN-04**: Если формы слова нет в словаре (running, ran, books), ищется базовая форма (run, book) по простым окончаниям и списку неправильных глаголов

### Popup

- [ ] **POP-01**: Попап появляется у курсора в пределах экрана: слово, статья словаря или перевод, исходная строка, «искали N раз»
- [ ] **POP-02**: Попап закрывается по клику, Esc, потере фокуса или таймауту
- [ ] **POP-03**: Каждое нажатие что-то показывает: «не найдено», «нет сети», «не установлен пакет X»

### Data

- [ ] **DATA-01**: Каждое переведённое слово сохраняется с переводом, контекстом (распознанной строкой), счётчиком поисков, временем первого и последнего поиска
- [ ] **DATA-02**: Перед подсчётом слово нормализуется: регистр, крайняя пунктуация, кавычки, `'s`
- [ ] **DATA-03**: Выделенная фраза из 2–4 слов переводится и сохраняется как одна запись; длинный текст только показывается

### Word List

- [ ] **LIST-01**: Окно со списком сохранённых слов, по умолчанию отсортированных по счётчику; сортировка кликом по колонкам
- [ ] **LIST-02**: В окне есть поиск и удаление слов

### Install

- [ ] **INST-01**: `install.sh` на Arch ставит зависимости (pacman + kdotool), словарь Mueller 7 и регистрирует хоткей
- [ ] **INST-02**: README на русском: установка, ручная настройка хоткея, `lookup --doctor` для диагностики

### Performance

- [ ] **PERF-01**: Медиана от нажатия хоткея до попапа не больше 2 с на железе друга

## v2 Requirements

### Learning

- **LEARN-01**: Интервальное повторение карточек (Again/Hard/Good/Easy), как у Lookupper
- **LEARN-02**: Экспорт в Anki / Quizlet / CSV
- **LEARN-03**: Статус слова «знаю / учу»

### Dictionaries

- **DICT-01**: Форматы DSL, MDX, Yomitan
- **DICT-02**: Произношение (аудио), CEFR, синонимы

### Card

- **CARD-01**: Скриншот сцены и приложение-источник в карточке слова

## Out of Scope

| Feature | Reason |
|---------|--------|
| X11, GNOME и другие DE | У друга KDE Plasma 6, X11-сессию убрали в Plasma 6.8 |
| Машинный офлайн-перевод (Argos) | Для слов хватает словаря, фразы идут в онлайн-фолбэк |
| Языки кроме EN→RU | Друг просил английский |
| Геймпад, перевод всего экрана | Не просили |
| Демон и трей | Одноразовый процесс проще; демон, только если медиана > 2 с |
| AUR-пакет | Для MVP хватит `install.sh` |
| Лемматизация через NLTK/spaCy | Тяжёлая зависимость; хватит TRAN-04 |
| Реверс-инжиниринг Lookupper | Поведение видно снаружи, риск EULA |
