# LookUp Linux

## What This Is

Аналог [Lookupper для Windows](https://lookupper.com/) для Linux (Arch + KDE Plasma); поведение копируем с него. Наводишь курсор на слово, жмёшь хоткей, программа через OCR читает слово под курсором (или берёт выделенный текст) и показывает русский перевод в оверлее рядом с курсором. Каждое переведённое слово сохраняется в локальную базу вместе со счётчиком, сколько раз его искали. Делается для друга, который переходит на Linux и не хочет разбираться в Claude.

## Core Value

Хоткей над английским словом даёт перевод в оверлее у курсора примерно за 1–2 секунды, и слово попадает в базу со счётчиком.

### Active

- [ ] Глобальный хоткей запускает поиск (через системные «Комбинации клавиш» KDE, которые вызывают команду)
- [ ] Выделенный мышкой текст, если он есть и новый, переводится без OCR
- [ ] Без выделения берётся скриншот вокруг курсора, OCR (EN), выбирается слово под курсором
- [ ] Перевод EN→RU: сначала локальный офлайн-словарь в формате StarDict (как у Lookupper: друг может подложить любой), онлайн-фолбэк, если слова нет в словаре или выделена фраза
- [ ] Оверлей рядом с курсором: слово, перевод или статья словаря и исходная строка; закрывается по клику, Esc или таймауту
- [ ] SQLite-база: слово, перевод, контекст (распознанная строка), счётчик поисков, первое и последнее время
- [ ] Окно со списком сохранённых слов, сортировка по счётчику
- [ ] Инструкция по установке на Arch (pacman-пакеты + настройка хоткея в KDE)

### Out of Scope

- Wayland GNOME / другие DE — у друга KDE, поддержка остальных не нужна для MVP
- Машинный офлайн-перевод (Argos) — для слов хватает словаря, фразы идут в онлайн-фолбэк
- Другие языки, кроме EN→RU — друг просил английский
- Форматы словарей DSL, MDX, Yomitan — в MVP только StarDict, самый распространённый
- Интервальное повторение и экспорт в Anki/Quizlet/CSV — у Lookupper есть, но для MVP хватит базы со счётчиком; это следующий milestone
- Скриншот сцены, аудио-произношение, CEFR, синонимы, приложение-источник — украшения карточки, а не ядро
- Геймпад, перевод всего экрана, 53 языка — не просили
- Демон в фоне / трей — одноразовый процесс на хоткей проще; переходить, только если запуск окажется медленным
- AUR-пакет — для MVP хватит скрипта установки

## Context

- **Референс — [Lookupper для Windows](https://lookupper.com/)**, «приложение мечты» друга. Копируем поведение и UX, не код. Что умеет оригинал:
  - по клику/хоткею (и кнопке геймпада) переводит слово поверх любого приложения, включая полноэкранные игры; делает только скриншот, без инъекций в процесс;
  - офлайн OCR, читает даже пиксельные и рукописные шрифты;
  - офлайн-словари бесплатно и без лимитов (Yomitan, StarDict, MDX, Lingvo DSL, совместимость с GoldenDict); облачные словари и перевод — 50 слов в день во free;
  - в попапе: определение, часть речи, синонимы, транслитерация, CEFR-уровень, исходное предложение с переводом, приложение-источник; произношение онлайн;
  - сохранённое слово становится карточкой (контекст, перевод, аудио, скриншот сцены) с интервальным повторением Again/Hard/Good/Easy; экспорт в Anki/Quizlet/CSV, синк с Anki в Pro;
  - перевод всего экрана (отдельный Screen translator), 53 языка;
  - Free: до 1000 сохранённых слов; Pro: $10 в месяц или $84 в год.
  Источник: lookupper.com (главная, FAQ, тарифы).
- **Из этого в MVP берём ядро**: хоткей → слово под курсором через OCR → попап (перевод или статья словаря + исходная строка) → слово сохраняется в базу со счётчиком и контекстом. Остальное в Out of Scope.
- Целевая система друга: Arch Linux + KDE Plasma (скорее всего Plasma 6, Wayland-сессия по умолчанию; возможна X11).
- Тестирование: VM с Arch + KDE у Дениса.
- Wayland мешает трём вещам: глобальному хоткею, чтению позиции курсора и позиционированию окна. Предварительные обходы:
  - хоткей: пользовательская комбинация KDE, которая запускает команду (работает и в X11, и в Wayland);
  - курсор: скрипт KWin (`workspace.cursorPos`) через D-Bus или `kdotool`;
  - скриншот: `spectacle` в фоновом режиме;
  - оверлей: Qt через XWayland (`QT_QPA_PLATFORM=xcb`), чтобы окно можно было разместить у курсора;
  - выделение: PRIMARY selection (`wl-paste --primary` или Qt clipboard).
- HiDPI-масштаб и несколько мониторов дают расхождение между логическими координатами курсора и пикселями скриншота.
- Режим работы: ponytail (минимальное полное решение, без лишних абстракций).

## Constraints

- **Платформа**: Arch + KDE Plasma, X11 и Wayland — так у друга
- **Стек**: Python 3 + PySide6/PyQt6 + tesseract из pacman, без pip-зависимостей там, где хватает stdlib — проще ставить на Arch
- **Перевод**: основной источник — офлайн-словарь; онлайн-фолбэк (Google gtx блокируется с 09.2026 — перебор client= + запасной провайдер) не должен ломать попап при ошибке
- **Задержка**: хоткей → оверлей ≤ ~2 с
- **Приватность**: OCR и словарь работают офлайн; в сеть уходит только слово или фраза при фолбэке; скриншоты не сохраняются
