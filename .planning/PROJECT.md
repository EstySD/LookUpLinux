# LookUp Linux

## What This Is

Аналог [Lookupper для Windows](https://lookupper.com/) для Linux (Arch + KDE Plasma 6); поведение копируем с него. Наводишь курсор на слово, жмёшь хоткей, программа через OCR читает слово под курсором (или берёт выделенный текст) и показывает у курсора карточку: транскрипция, значения из офлайн-словарей, исходное предложение с переводом. Найденные слова сохраняются в локальную базу со счётчиком поисков; слова можно добавить в карточки и повторять по интервальной системе, экспортировать в Anki. Живёт в трее. Делается для друга, который переходит на Linux. Сразу прод-версия, а не MVP (решение от 2026-10-24).

## Core Value

Хоткей над английским словом даёт перевод в оверлее у курсора примерно за 1–2 секунды, и слово попадает в базу со счётчиком.

- ✓ Фоновый клиент, замена попапа, новое PRIMARY-выделение и карточка в теме KDE с сохранением слова и учебной карточки (TRIG-02, TRIG-03, CAPT-02, POP-01..POP-05) — Phases 5–7; итоговые регрессии Phase 8 проходят.
- ✓ Действующие настройки, папка словарей и rescan, автозапуск, Arch-пакет и диагностика (SET-01, TRIG-04, INST-01, INST-02) — Phase 7; 701 тест в VM без пропусков и 14 продуктовых нативных проверок. - ✓ Список слов, неизменяемые учебные карточки, интервальное повторение и CSV/Anki экспорт (LIST-01, LIST-02, POP-04, LEARN-01, LEARN-02) — Phase 6; 640 тестов в VM без пропусков, нативные окна и реальный импорт Anki 26.9.3 проверены агентами.

- ✓ Нормализация слова и запись в SQLite: перевод, контекст, счётчик, время первого и последнего поиска, версионируемая схема (DATA-01, DATA-02) — Phase 1

- ✓ OCR готового изображения: ограниченный ближайший поиск, отказ на мусоре, составные и дефисные слова (CAPT-03, CAPT-04) — Phase 3; 96 точек на 16 Breeze-рендерах, реальные захваты рабочего стола проверяются в Phase 4

## Context

- **Референс — [Lookupper для Windows](https://lookupper.com/)**, «приложение мечты» друга. Копируем поведение и UX, не код. Что умеет оригинал:
  - по клику/хоткею (и кнопке геймпада) переводит слово поверх любого приложения, включая полноэкранные игры; делает только скриншот, без инъекций в процесс;
  - офлайн OCR, читает даже пиксельные и рукописные шрифты;
  - офлайн-словари бесплатно и без лимитов (Yomitan, StarDict, MDX, Lingvo DSL, совместимость с GoldenDict); облачные словари и перевод — 50 слов в день во free;
  - в попапе: определение, часть речи, синонимы, транслитерация, CEFR-уровень, исходное предложение с переводом, приложение-источник; произношение онлайн;
  - сохранённое слово становится карточкой (контекст, перевод, аудио, скриншот сцены); экспорт в Anki/Quizlet/CSV, синк с Anki в Pro. Документация показывает Again/Hard/Good/Easy в Anki; встроенное повторение Lookupper не подтверждено. Собственное повторение LookUpLinux остаётся решением LEARN-01;
  - перевод всего экрана (отдельный Screen translator), 53 языка;
  - Free: до 1000 сохранённых слов; Pro: $10 в месяц или $84 в год.
  Источник: lookupper.com (главная, FAQ, тарифы).
- **Из этого берём** функции принятого v1 из REQUIREMENTS.md; список возможностей оригинала сам по себе не обещает полное совпадение. Расширение от 2026-10-27 добавляет многострочный контекст, значение выбранного слова по контексту и проверки реальных полноэкранных игр. Аудио, CEFR, синонимы, скриншот сцены, Yomitan, синк с Anki, геймпад и перевод всего экрана в v1 не входят.
- Целевая система друга: Arch Linux + KDE Plasma 6. В Plasma 6.8 (сейчас в Arch 6.8.1) X11-сессию убрали, поэтому только Wayland.
- Тестирование: Windows-хост и независимая VirtualBox VM `lookup-gsd-07` с Arch + KDE Wayland. Исходная `arch-kde` используется другим проектом и не управляется нашими проверками. Проверки на железе друга нет; ограничения VM и историческое исключение Phase 7 сохранены в отчётах.
- Wayland мешает трём вещам: глобальному хоткею, чтению позиции курсора и позиционированию окна. Обходы по итогам research:
  - хоткей: `.desktop` с `X-KDE-Shortcuts` + `kbuildsycoca6` (команда будит фоновое приложение); запасной вариант — ручная настройка в «Комбинациях клавиш»;
  - курсор, геометрия монитора, перемещение и активация попапа: `kdotool` (AUR или готовый бинарник с GitHub); если он не пройдёт VM-спайк, свой скрипт KWin;
  - скриншот: KWin ScreenShot2 по D-Bus с UnixFD; Spectacle был сравнительным транспортом спайка;
  - OCR: `tesseract` через subprocess, вывод TSV;
  - выделение: `wl-paste --primary` (wl-clipboard ≥ 2.3.0) с таймаутом; используется, только если выделение новое;
  - словарь по умолчанию: Mueller 7 EN→RU (GPL, 46 тыс. статей, StarDict).
- HiDPI-масштаб и несколько мониторов дают расхождение между логическими координатами курсора и пикселями скриншота.
- Режим работы: ponytail (минимальное полное решение, без лишних абстракций) — применяется к реализации, а не к объёму фич.

## Constraints

- **Платформа**: Arch + KDE Plasma 6, Wayland; X11-сессии в Plasma 6.8 больше нет
- **Стек**: Python 3 + PyQt6/QtDBus + tesseract + wl-clipboard из pacman, kdotool из AUR; захват через KWin ScreenShot2, без pip-зависимостей там, где хватает stdlib
- **Перевод**: основной источник — офлайн-словари; онлайн (Google gtx блокируется с 09.2026 — перебор client= + запасной провайдер) при ошибке не ломает попап
- **Задержка**: хоткей → попап, медиана ≤ 1,5 с в VM Дениса
- **Приватность**: OCR и словари работают офлайн; в сеть уходят только слово, фраза или предложение для онлайн-перевода; скриншоты не сохраняются
- **Внешний вид**: тема KDE (Breeze, светлая и тёмная), не копия дизайна Lookupper
