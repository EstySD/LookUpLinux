<objective>
Build the three leaf codecs that the dictionary readers sit on: an LZO1X decompressor and a RIPEMD-128 digest (both missing from the stdlib, both needed for MDX, D-07/D-34) and a dictzip random-access reader (needed for `.dict.dz` and `.dsl.dz`, D-08).

Purpose: Decide the Phase 2 research flag in favour of "no extra package": MDX LZO blocks and Encrypted=2 key info are read with stdlib-only code that is verified against the real library output, so the PKGBUILD in Phase 7 gets no new dependency.
Output: `lookup/lzo.py`, `lookup/ripemd128.py`, `lookup/dictzip.py`, their tests, the LZO vector fixture and a dictzip test writer.
</objective>
