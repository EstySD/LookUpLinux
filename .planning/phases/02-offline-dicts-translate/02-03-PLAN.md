<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.json to program | user-editable file, later written by the Phase 7 settings window; content is untrusted until validated |
| cache directory to program | index files in a user-writable directory could be replaced by another local process |
| dictionary text to UI | article text from third-party files will be shown in a popup |
| downloaded WordNet files to generator | input is third-party data processed once at build time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-08 | Tampering | config.load (type confusion, oversized file, `clients` value reaching a request URL, `id` reaching a path) | high | mitigate | Size cap, strict per-key type checks, `clients` limited to `^[A-Za-z0-9._-]{1,32}$`, dictionary `id` is a plain string never joined to a path in this module (the search layer matches it against discovered ids only); tests cover each malformed case |
| T-02-09 | Tampering / elevation | index cache files replaced or corrupted by another local process | high | mitigate | JSON only (no pickle or marshal), wrapper records path, size, mtime and format and must match the source file, size cap, 0600 file in 0700 directory, any failure is a miss that rebuilds from the dictionary |
| T-02-10 | Tampering | markup or control/bidi characters in dictionary text reaching the popup | medium | mitigate | `html_to_text` and `clean_text` return plain text only, remove Cc/Cf characters, never raise; UI renders plain text (PITFALLS markup injection) |
| T-02-11 | Information disclosure | WordNet licence obligations | low | accept | Notice shipped in `lookup/data/NOTICE-wordnet.txt`; no Princeton name used in promotion |
</threat_model>
