  <action>
Create `lookup/dsl.py` (stdlib: `mmap`, `re`, `os`; module docstring repeats V7).
- Encoding detection from the first bytes: `FF FE` UTF-16LE (skip 2), `FE FF` UTF-16BE (skip 2), `EF BB BF` UTF-8 (skip 3), `23 00` UTF-16LE without BOM, `00 23` UTF-16BE without BOM, anything else UTF-8 without BOM. Newline in the file's encoding is `\n` (UTF-8) or `\n\x00` / `\x00\n` (UTF-16); a carriage return before it is stripped when decoding a line.
- Source access: plain `.dsl` through `mmap` (read-only; empty file is `DictError("empty")`), `.dsl.dz` through `DictzipFile` (cold index uses `read_all(MAX_DSL_BYTES)`, later reads use `read(offset, length)`). A source above `MAX_DSL_BYTES` is `DictError("too_large")`. Offsets are byte offsets into the raw (undecoded) source after the BOM. For UTF-16 the line scanner searches for the encoded newline with `find` and accepts a hit only at an even offset from the start of data (otherwise continue searching from the next byte), so characters whose bytes contain 0x0A never split a line; each line is decoded individually with `errors="replace"`.
- Scanner (one pass, sequential): header lines start with `#` at the beginning of the file region before the first headword; values are the text inside the first pair of double quotes (`#NAME`, `#INDEX_LANGUAGE`, `#CONTENTS_LANGUAGE`; other `#` lines ignored). After the header: a non-empty line that does not start with a space or tab is a headword line; a line starting with a space or tab is body; blank lines are skipped. Consecutive headword lines form a group; the first body line after a group starts an article, and the article ends before the next headword line (or at end of data). Track the byte range of the body (start of the first body line to the end of the last non-blank body line). A group with no body is dropped. An article whose body is larger than `MAX_ARTICLE_BYTES` is skipped and counted in `skipped_entries`. Registered articles count in `entry_count`.
- `expand_headword(text)`: process backslash escapes (a backslash makes the next character literal, including braces, brackets and backslash), treat unescaped `{...}` as an optional part giving a variant with and without it, expand left to right in stable order and stop at `MAX_VARIANTS` (32) results (D-08, T-02-22), strip whitespace, drop empty results, de-duplicate. Every expanded spelling is folded with `fold_key` and registered; the original headword (first expansion) is kept for `Article.headword`.
- Index: `dict[folded_key] -> list of (offset, size, headword)`. Cache with `index_cache_load(path, INDEX_TAG)` / `index_cache_save`: payload holds encoding name, BOM length, name, languages, counts and the entries; on load validate types and that every offset+size lies inside the source, and rebuild when anything is off (T-02-09). `lookup(key)` reads each article body with one `mmap` slice or `DictzipFile.read`, decodes it and builds the Article through the converter added in Task 2; in this task the converter is a minimal function returning the decoded lines joined with newlines as `text` with `transcription=None` and empty `senses`.
- `DslDictionary` implements the shared contract; `close()` closes the mmap or DictzipFile. Zero registered articles raises `DictError("empty")`. Any unexpected `OSError` or decode failure while opening becomes `DictError("corrupt")`.

Create `tests/_dsl_writer.py` (`write_dsl` per the artifacts list: writes `#NAME`, `#INDEX_LANGUAGE`, `#CONTENTS_LANGUAGE` header lines, then for each entry the headword lines unindented and the body lines indented by a space or tab, in the requested encoding and BOM mode, optionally wrapping the result with `make_dictzip` and a `.dz` suffix). Create `tests/test_dsl.py` with `ExpandHeadwordTests` and `DslReaderTests` per the behaviours; close dictionaries through `addCleanup`.
