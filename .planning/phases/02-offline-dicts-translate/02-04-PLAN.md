<objective>
Build the online translation client: Google `translate_a/single` through `urllib` with an ordered `client=` list (D-13), strict classification of every failure into the five fixed reasons (D-14, D-16), a shared 3-second budget (D-16), and MyMemory as the independent fallback for phrases and sentences (D-15, D-31). Parsing is driven by real captured responses.

Purpose: TRAN-02 and TRAN-05 need a client that fails fast, names the reason, never leaks the query and never breaks the answer; the orchestrator (plan 09) only calls `translate_online`.
Output: `lookup/online.py`, `tests/test_online.py`, response fixtures.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| program to Google / MyMemory | only the word, phrase or sentence leaves the machine; nothing else (no identity, key or e-mail) |
| remote response to parser | HTML block pages, oversized bodies, odd JSON, wrong hosts are untrusted |
| config client names to request URL | the `clients` list comes from a user-editable file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-12 | Information disclosure | exception messages and tracebacks naming the URL or query | high | mitigate | `TranslateError` message is only the reason code; every transport exception is converted with `raise ... from None`; test asserts the query never appears in str/repr and `__cause__` is None |
| T-02-13 | Spoofing | redirect to another host, downgraded or unverified TLS | high | mitigate | Default urllib certificate verification only (no custom SSL context); response host compared with the expected provider host; only the two hard-coded hosts are ever requested |
| T-02-14 | Denial of service | oversized or slow response, hung socket | medium | mitigate | 1 MiB body cap, chunked read with a wall-clock check against the shared deadline, per-attempt timeout equals the remaining budget |
| T-02-15 | Tampering | malformed or hostile JSON from the network | medium | mitigate | Safe-index helper on every level, type checks, cap on parts and terms, fixed reason mapping; fixtures cover garbage, wrong shapes and invalid UTF-8 |
| T-02-16 | Information disclosure | user identity sent to a third party (MyMemory e-mail or key parameters) | medium | mitigate | URL builders include only q and langpair; test asserts no `de` or `key` parameter |
| T-02-17 | Tampering | `clients` value injecting extra URL parameters | medium | mitigate | Names validated with `^[A-Za-z0-9._-]{1,32}$` before use and the value is passed through `urlencode` |
</threat_model>
