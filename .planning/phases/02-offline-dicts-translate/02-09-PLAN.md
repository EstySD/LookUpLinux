<objective>
Write the orchestrator that ties dictionaries, cache, online translation and the database together: classify the input, search dictionaries, fall back to the cache and the network, translate the context sentence in parallel, and apply the exact save rules for words, phrases and sentences.

Purpose: TRAN-02, TRAN-03, TRAN-05 and DATA-03 live here. Phase 3 and the Phase 5 daemon call `translate.lookup` with already opened dictionaries and a connection, so the API takes both as arguments and works without either of them.
Output: `lookup/translate.py` and `tests/test_translate.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| program to network | only the word, phrase or sentence (and the context sentence) may leave the machine |
| database file to program | cached payloads and meta values are read back and must be treated as untrusted |
| background thread to main thread | the context-translation thread runs network code beside the SQLite connection owner |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-35 | Information disclosure | text sent to third parties beyond the lookup text | high | mitigate | Network used only when the dictionaries miss, for phrases absent from dictionaries and for sentences; requests carry only `prepare_text` output (capped at 1000 characters); `online=False` and `--offline` stop all traffic; test asserts zero network calls on dictionary hits and offline runs |
| T-02-36 | Tampering | SQL for translations and meta | high | mitigate | Every statement uses bound parameters; test with quote/semicolon keys |
| T-02-37 | Tampering | poisoned cache payload (edited database) | medium | mitigate | `OnlineResult.from_payload` validates shape and types; invalid payload is a cache miss that gets overwritten |
| T-02-38 | Denial of service | thread leak or blocked join | medium | mitigate | Daemon thread, join bounded by `CONTEXT_JOIN_S`, no shared SQLite connection, hang-guard tests |
| T-02-39 | Information disclosure | logging or error text containing the query | high | mitigate | Module never prints or logs; only reason codes are stored in `Result`; verified later by `tests/test_privacy.py` (plan 10) |
</threat_model>
