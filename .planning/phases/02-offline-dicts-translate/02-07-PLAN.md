<objective>
Implement the MDX (MDict) reader on the stdlib: header, keyword section, key info (with Encrypted=2), key blocks, record blocks with zlib, no compression and LZO, redirects, HTML to text, and a validated index cache.

Purpose: TRAN-01 lists MDX as a required format and the research flag asked for LZO without a package; plans 02 provided `lookup.lzo` and `lookup.ripemd128`. Since no real MDX is available, this plan builds an independent test writer and leans on checksums and real vectors.
Output: `lookup/mdx.py`, `tests/_mdx_writer.py`, `tests/test_mdx.py`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MDX file to reader | every count, size, offset, checksum and compressed stream is untrusted |
| cache file to reader | JSON index in a user-writable directory |
| record text to UI | HTML from third-party dictionaries |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-26 | Denial of service | zlib and LZO decompression bombs, declared sizes in the gigabytes | high | mitigate | Declared sizes capped (`MAX_MDX_BLOCK`, `MAX_KEY_INFO`) before any allocation; `decompressobj().decompress(data, declared + 1)` and the bounded `lzo.decompress`; result length must equal the declared size |
| T-02-27 | Denial of service / tampering | malformed counts, offsets, block tables, header length | high | mitigate | `MAX_BLOCKS` and header cap; file-size checks for every table; offsets beyond the record range skipped and counted; struct and zlib errors converted to DictError; tests for each |
| T-02-28 | Tampering | corrupted or modified blocks accepted silently | medium | mitigate | Adler-32 verified for the header, keyword header, key info, key blocks and each record block; failing record skipped, failing structure is DictError("checksum") |
| T-02-29 | Denial of service | `@@@LINK=` loops or long chains | medium | mitigate | At most 3 hops with a visited set; tests for loop, long chain and missing target |
| T-02-30 | Information disclosure | registration-encrypted dictionaries | low | accept | Not supported by design (D-07); reported with a fixed reason code |
</threat_model>
