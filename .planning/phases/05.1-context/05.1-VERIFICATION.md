## Resolved Blocking Reproduction

Executed against the submitted code without modifying production or fixtures:

```python
from tests.test_ocr import paragraph, ContextTests
case = ContextTests()
for lines in (
    ('A: They stood on the bank', 'B: She deposited money.'),
    ('GUARD: They stood on the bank', 'MERCHANT: She deposited money.'),
):
    selected = case.select(paragraph(*lines), 'bank')
    print(selected.context, selected.context_complete)
```

Before the fix, both outputs contained both speakers and `context_complete=True`. The speaker guard accepted only title-case multi-letter names. The next speaker's punctuation made the merged text appear reliable.

The bounded label guard now recognizes `[A-Za-z][A-Za-z0-9_ -]{0,63}:` at the beginning of a continuation. Added regression exercises A/B, GUARD/MERCHANT, Old Guard/Young Merchant, NPC_1/NPC_2 and alice/bob. All retain only the selected speaker's available fragment with `context_complete=False`. The original Alice/Bob case alone was a misleadingly narrow passing test; the new cases close that coverage gap. No override was used.
