# Phase 5.1 Validation Strategy

Framework: stdlib unittest. Baseline parent evidence: 46 tests passed in OCR/early translation/app/store before changes. Every implementation task adds behavioral cases before implementation; no separate scaffold wave is required because unittest discovers the named new test modules directly.

Quick feedback: `python -m unittest tests.test_ocr tests.test_context tests.test_translate_ready tests.test_app tests.test_store` after the relevant modules exist. Full regression: `python -m unittest discover -s tests` after each plan. Target latency: each focused task command under 60 seconds; long actual VM harnesses report progress and bounded results separately.

| Task | Requirements | Automated verification | Actual acceptance evidence |
|---|---|---|---|
| 01-1 | CAPT-05 | tests.test_ocr, tests.test_ocr_image, tests.test_ocr_cli | Geometry/source-span edge cases |
| 01-2 | CAPT-05 | tests.test_context_images | Real Tesseract controlled 2–4-line images, columns/dialogue/captions/sentences/hyphen/ambiguity |
| 02-1 | TRAN-06 | tests.test_context, tests.test_online, tests.test_privacy | Captured positive bank/repeated/multiline/phrase responses and malformed controls |

| 03-1 | CAPT-05, TRAN-06 | tests.test_translate_ready, tests.test_app | Delayed early readiness, disabled network, stale/close/count invariants |
| 03-2 | CAPT-05, TRAN-06 | tests.test_app_gui, tests.test_cli, tests.test_privacy | Separate native word/sentence fields and limited-fragment label |
| 03-3 | CAPT-05, TRAN-06 | full unittest discovery | Actual provider + archvm OCR/popup/persistence/timing harness |

New files tests/test_context.py and tests/test_context_images.py are created in the same tasks as their tested contracts. Tests must assert observable outputs, refusal, source correspondence and lifecycle effects rather than mirror implementation helpers.

No mocked or skipped test proves real OCR/provider/popup acceptance. Host lacks Tesseract; use existing `ssh archvm` target. If VM unavailable, record exact acceptance blocker and leave affected criteria unverified. Agent acceptance is never labeled human testing. Numeric timing measurements do not close Phase 8 PERF-01 or GAME-01.
