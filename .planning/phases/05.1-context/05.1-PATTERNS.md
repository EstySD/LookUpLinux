# Phase 5.1 Pattern Map

| Change | Existing analog | Constraint |
|---|---|---|
| Context/occurrence recovery | lookup/ocr.py select_word, _units, Word.line_id | Keep bounded selection and compatible positional Selection construction |
| Synthetic image harness | tools/gen_ocr_fixtures.py, tools/calibrate_ocr.py | Controlled public text, actual OCR comparison, explicit skips/failures |
| Context provider | lookup/online.py _fetch, TranslateError | Fixed HTTPS host, redirects refused, bounded body/deadline, private reason codes |
| Cache/migration | lookup/translate.py cache_get/cache_put, lookup/store.py _v2 | Worker-only SQLite, validate cached data, additive guarded migration |
| Enrichment lifecycle | lookup/translate.py on_ready; lookup/app.py Engine.ready/current | Detached early result, guarded accepted generation, exactly one history count |
| Popup field | lookup/gui.py context_value/update_context/PlainBlock | Separate plain-text word/sentence states; native palette and accessible labels |
| Target integration | tools/check_app.py | Throwaway state, synthetic fixtures, actual target evidence and restoration |

No new dependency, service account, GUI framework or background daemon is needed.
