<interfaces>
Existing normalize(text: str) -> str | None rejects digits/non-Latin/interior
punctuation and preserves Latin apostrophes/hyphens. DictSet.find(text) returns
SearchResult(articles: tuple=(), lemma: str|None=None); bool(result) means
articles exist. It does not save or call a network provider.

Create frozen records with these contracts (tuple box = left, top, width, height):
- Word(text: str, box: tuple[float,float,float,float], confidence: float,
  line_id: tuple[int,int,int,int], order: int): retain raw text, including rejected
  lexical tokens, so their positions remain barriers.
- Transform(left: float=0, top: float=0, scale_x: float=1, scale_y: float=1,
  border: float=0): original_xy(u,v) and original_box(box) invert actual crop,
  enlargement and border; scale factors must be positive and finite.
- Selection(word: str, line: str, candidates: tuple[str,...],
  box: tuple[float,float,float,float], confidence: float): normalized selected
  lexical word; raw reconstructed source line; ordered normalized compound pairs
  containing that word; box in original image pixels.
- OcrError(reason): fixed controlled codes, no paths/text/raw output in message.
- parse_tsv(data: bytes, transform: Transform|None=None) -> tuple[Word,...].
- select_word(words, point: tuple[float,float]) -> Selection|None.
- choose_query(selection: Selection, dictset=None) -> str: first candidate whose
  DictSet.find is truthy, otherwise selection.word. No translation or storage.
These records are the contract for Plans 02/03; implement their behavior here.
</interfaces>
</context>
