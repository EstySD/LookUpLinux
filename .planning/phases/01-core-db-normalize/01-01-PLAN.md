Start from the verified reference implementation in RESEARCH "Code Examples" item 1 and apply exactly two behavioural changes, both locked after the research: D-16 (contraction exceptions) and D-17 (digit rejection). Pipeline, in this order:
   a. Raise `TypeError` when `text` is not a `str` (message names the type only, never the value).
   b. Explicit translate tables BEFORE NFKC (D-01, D-18): apostrophe-like U+2018 U+2019 U+201A U+201B U+02BC U+2032 U+00B4 U+0060 map to `'`; double-quote-like U+201C U+201D U+201E U+201F U+00AB U+00BB U+2033 U+2039 U+203A and the ASCII `"` map to `"`; dash-like U+2010 U+2011 U+2012 U+2013 U+2014 U+2212 map to `-`. NFKC alone does not fold these (Pitfall 2).
   c. `unicodedata.normalize("NFKC", ...)`.
   d. Remove every character whose `unicodedata.category` is `Cf` (soft hyphen U+00AD, zero-width space, BOM) per D-18.
   e. `casefold()` then NFC (D-03: case always folded, proper nouns included).
   f. Remove every character of category `Mn` (stray combining marks, e.g. the dot left by dotted capital I). Latin diacritics already composed by NFC (`é`) are NOT `Mn` and stay (D-18).
   g. `split()` on whitespace, which collapses runs of spaces/tabs/newlines/nbsp (D-05). No tokens: return None.
   h. Per token, in this order: (1) per D-17, if any character satisfies `str.isnumeric()` return None - this check runs on the raw token BEFORE any edge trimming, so `run1`, `mp3`, `1st`, `abc2`, `4k` are all rejected; (2) trim leading/trailing characters that are not `str.isalpha()` with `_strip_edges` (punctuation, quotes, brackets, `'`, `-`); (3) repeat until the token no longer changes: stop when the token is in `CONTRACTIONS` (D-16), else drop a trailing `'s` when the token is longer than 2 characters, then trim edges again. The loop only ever shortens the token, so it terminates and makes the function idempotent (`book's's` becomes `book`; `dogs'` becomes `dogs` through the edge trim). An empty token returns None for the whole input.
   i. Validate each token character: `'` and `-` are allowed inside (D-02); every other character must be alphabetic AND `unicodedata.name(c, "")` must start with `LATIN` (D-04: Cyrillic, mixed scripts, CJK and any other punctuation inside a token give None; D-18: diacritics stay).
   j. Join tokens with a single space (D-05). If the key is shorter than 2 characters and is not `a` or `i`, return None (D-04).
   `CONTRACTIONS` is a `frozenset` of exactly these 11 strings (D-16): `it's`, `let's`, `that's`, `what's`, `he's`, `she's`, `there's`, `here's`, `who's`, `where's`, `how's`.
   No lemmatisation (D-06): `running` stays `running`. The module performs no I/O, no printing and no use of the logging module. The only import is `unicodedata`. Add a short docstring on `normalize` stating the contract: returns the counting key for a word or 1-N word phrase, or None to reject; the caller must not touch the database on None (D-04).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OCR / selection text -> normalize() | Text recognised from the screen or taken from the clipboard is untrusted; the resulting key later flows into SQL (plan 01-02) and, in later phases, to the network |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `normalize()` output reaching SQL/network | medium | mitigate | Latin-only check, allowed inner characters limited to `'` and `-`, digit rejection (D-17), length rule (D-04): the output alphabet is Latin letters, `'`, `-` and space. The fuzz test asserts that alphabet on every non-None result. |
| T-01-02 | Denial of service | `normalize()` on very long input | low | accept | Single linear pass, no regular expressions; the possessive loop strictly shortens the token each pass so it terminates. The input length cap belongs to the call site (DATA-03, Phase 2). |
| T-01-03 | Information disclosure | `normalize()` errors | low | mitigate | No I/O, no logging; the `TypeError` message names the type, never the value. |
| T-01-SC | Tampering | Dependency supply chain | low | accept | Phase installs no packages; stdlib only (RESEARCH "Package Legitimacy Audit": not applicable). |
</threat_model>
